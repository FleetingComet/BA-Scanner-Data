# BA-Scanner-Data

Community-maintained processed data used by [Blue Archive Resource Scanner](https://github.com/FleetingComet/Blue-Archive-Resource-Scanner).

## About

This repository contains processed and structured data used by the scanner to identify and map Blue Archive resources, students, equipment, and related information.

The data includes **processed information based on [Schale DB](https://schaledb.com/)**, an unofficial database for the mobile game **Blue Archive** developed by Nexon Games.

This repository is maintained independently from Nexon and is **not affiliated with, endorsed by, or sponsored by Nexon or Blue Archive**.

## Purpose

The data in this repository is provided so that the scanner can receive data updates independently from the scanner's source code.

The scanner may download the latest version of this repository's data when data synchronization is enabled.

## Data Processing

The data is processed and structured for use by the Blue Archive Resource Scanner. It is not intended to represent or reproduce Nexon's original game files or assets.

For information about the original data source, please refer to [Schale DB](https://schaledb.com/).
